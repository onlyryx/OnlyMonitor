# Only Monitor v0.3 Resident Reliability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 交付普通用户可控制登录启动、隐藏启动可恢复、配置及安装升级兼容的 v0.3.0 Alpha。

**Architecture:** 保留唯一 Rust worker；新增独立启动状态 commands，由 Rust 调官方 autostart。系统注册是真源，本地 schema 2 仅增加登录隐藏偏好。主窗口初始化隐藏，托盘就绪后按入口决定显示。UI 共享操作闸门，启动项操作不提交普通配置草稿。

**Tech Stack:** 现有锁定依赖及工具链，新增兼容的官方 tauri-plugin-autostart；不加 JS 插件。NSIS 使用小型生命周期钩子。

**Spec:** docs/superpowers/specs/2026-10-23-v0.3-resident-reliability-design.md（已获用户确认并授权连续实施）。

## Global Constraints

- Windows，版本 0.3.0、界面 v0.3.0 Alpha；保留 1／2／5 秒间隔、30 秒磁盘刷新、最近 60 秒最多 60 点。
- 登录启动默认不注册，hideOnAutostart 默认 true；手动启动及任何第二实例均显示已有主窗口。
- 不上传指标、不执行任意 Shell、不引入服务、不增加新指标、不部署网站或 DNS。
- 普通配置保存与启动项切换分开生效；启动失败不可假报成功，查询失败为未知。
- 无 Git 时文件备份替代提交；不创建仓库或覆盖已有备份。用户已明确要求计划后连续实施，不重复请求计划批准。
- 实际登录／重启系统／Explorer 重启需单独许可；可独立完成的开发与验证不停顿。发布时明确未验证场景。

## Review Focus

1. v0.2 配置迁移丢失原字段或加载时覆写文件 → Task 2 测试真实文件迁移与字节不变。
2. 注册失败或查询失败被当成关闭／成功 → Task 3 保留实际状态和独立错误的测试。
3. 第二实例的登录标记隐藏已有窗口／隐藏初始化托盘故障导致失联 → Task 3 入口决策真值表与实机启动检查。
4. 设置草稿被启动项操作隐式提交或并发回滚 → Task 4 延迟请求互斥、草稿隔离和刷新失败测试。
5. 升级内部卸载误删启动项或误删另一副本 → Task 5 隔离路径及精确值匹配安装测试。
