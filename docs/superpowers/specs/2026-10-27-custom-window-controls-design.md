# Only Monitor 自定义窗口控件设计

- **意图**：用与 Only Monitor 浅色视觉一致的应用内控件，替换难看的 Windows 系统标题栏按钮。
- **范围**：最小化、最大化／还原、关闭；可拖动标题区域；保持窗口缩放、关闭后按当前设置隐藏／退出，以及 Windows 11 Snap 布局。
- **不做**：自制 Snap 选择器、改变托盘／关闭设置语义、加入其他窗口管理功能。
- **方案**：`decorations: false`，使用 Tauri 2 的 `tauri-plugin-frame` 提供原生 Snap 命中层和窗口控件；React 提供品牌标题栏并为控件套用应用配色。插件版本固定；CSS 的标题栏高度和按钮宽度与原生 Snap 命中层保持一致。理由：Tauri 的无边框窗口本身不能为网页最大化按钮提供 Windows 11 Snap 命中；插件比自行维护 Win32 窗口过程更小、更易验证。
- **边界**：Snap 悬浮布局只适用于 Windows 11；其余 Windows 版本仍应能最小化、最大化、还原、关闭、拖动和缩放。当前应用目标为 Windows。
- **成功标准**：原生标题栏消失；自定义按钮样式融入浅色主题；按钮行为保持现有关闭语义；拖动和调整大小正常；悬停自定义最大化按钮可显示 Snap 布局并可成功贴靠。
