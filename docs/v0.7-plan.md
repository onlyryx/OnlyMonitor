# v0.7 Alpha：品牌与硬件洞察

目标：让 Only Monitor 成为帮助用户理解设备状态的日常工具，保持本地优先和清晰阅读。

1. 重绘浅色品牌标识和概览布局，以真实采样与可执行的本地观察为中心。验收：图标在窗口、托盘和常见尺寸下可辨认；小窗口能阅读并操作。
2. 实现磁盘实时读写，清楚区分首次采样、权限或设备不支持、计数器重置与有效零速率。验收：实际读写能改变对应速率；失败不沿用旧值；不要求管理员权限。
3. 验证 GPU 与温度数据源，只有取得可靠数据并确认口径后才展示数值。验收：无设备、驱动不支持、读取失败均明确显示；不把通用热区称作 CPU 温度。
4. 展示 Windows 物理磁盘报告状态，继续评估完整 S.M.A.R.T. 数据源和设备覆盖；不可用时保持明确提示，不根据磁盘容量推断健康。验收：不支持的设备不显示虚构健康结论。
5. 运行类型检查、测试、构建和原生窗口检查，记录设备与未验证边界。保留现有采样、托盘、设置和本地隐私约束。
6. 提供手动 Ping 和连接质量分析，默认不主动探测；显示目标、真实采样与统计口径。验收：普通权限下能收到真实回复，停止和睡眠恢复不会伪造或自动继续探测。

数据默认不上传，也不自动发起外部探测或 AI 请求。长时间历史仍默认只保留内存中的近期数据。
