## 能力边界

- GPU 展示 Windows GPU Engine 计数器中最活跃的四个引擎；同一引擎的进程计数相加，不代表整卡利用率，合计可能超过 100%。没有可读计数器或引擎时显示不可用。

- 性能计数器随现有采样器在本机读取，近期数据只存进程内存；没有新增上传、外部探测或 AI 请求。尚未做网络流量或长期资源专项监测。
