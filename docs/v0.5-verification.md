## 功能证据

- Collector 刷新当前进程 CPU 与驻留内存；每项排名最多 8 个，CPU 使用率按逻辑处理器数归一化。
- 新 PID／启动时间组合没有 CPU 基线时显示未知；CPU、内存排名采用 PID+启动时间内部身份防止 PID 重用带入基线。
- 进程快照保存在 `MonitorState` 当前值中，不进入 60 秒历史；采集失败清除当前进程快照并提供错误文字。
- 设置 schema 3 将提醒默认为关闭；schema 1／2 在内存迁移，加载不改写原配置文件。
- 提醒阈值由单元测试覆盖：CPU 或内存达到 90% 连续 30 秒触发；各指标各自保持一个高负载周期；低于 80% 连续 60 秒重新布防；采样缺失或超过 10 秒的间隔不会补算为连续时长。
- 托盘文案单元测试覆盖初始化、有效值和采集错误状态；托盘与提醒使用已有后台采样结果。
- Activity 页面测试覆盖 Overview 入口、CPU／驻留内存双排名最多 8 项、进程行同时展示两项资源、本地数据说明、初始化状态以及无进程控制按钮。
