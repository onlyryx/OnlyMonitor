## 边界

此处 CPU／内存数据是单机短时观察，不是稳态性能承诺，也没有覆盖不同硬件。逐条采样输出见当时会话，本文件仅保留汇总，没有独立原始样本文件，不作为优化效果的完整证据。

没有直接仪器化捕获隐藏／最小化期间 DOM 可见性事件或 UI 请求次数。前端测试使用模拟可见性事件；原生观察只支持窗口恢复与恢复后采样时间更新，不能据此断言期间轮询为零或每次采样均连续。真实休眠／唤醒、Explorer 重启和物理网卡断开仍未验证。
